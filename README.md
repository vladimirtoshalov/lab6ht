# Проверка четырехзначного числа на «перевертыш» (палиндром)

## Логическая часть
Для проверки числа без использования строк применяется математическое разделение на разряды с помощью операций деления нацело `/` и взятия остатка от деления `%`:
* `d1` (тысячи) — `num / 1000`
* `d2` (сотни) — `(num / 100) % 10`
* `d3` (десятки) — `(num / 10) % 10`
* `d4` (единицы) — `num % 10`

Итоговое логическое условие для определения перевертыша: `(d1 == d4 && d2 == d3)`.
